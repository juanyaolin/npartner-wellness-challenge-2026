## 背景

## 投影流程

1. 封面：「N-Partner 三比八大賽 2026 頒獎典禮」
2. 說明頁：本次頒獎不完全依照名次順序，也不完全依照獎金高低
3. 每位得獎者兩頁：
   - 第一頁：暱稱、參賽項目、名次、成績、獎金
   - 第二頁：真實姓名
4. 結尾頁

**調整順序**：得獎者是 `assets/js/awards.js` 開頭的一個陣列，一人一個物件。調整物件的先後就能改頒獎順序，不需要動其他程式。

**操作**：按 →、空白鍵、PageDown 或點擊滑鼠前進；按 ←、PageUp 退回。退回時不重播特效。按 M 切換靜音。全螢幕用瀏覽器的 F11。簡報筆送出的是 PageDown/PageUp，所以也能直接用。

## 動畫與音效

- 封面：深色背景配上流動的漸層光暈，標題逐字浮現。
- 第一頁：卡片翻轉飛入，獎金數字從 0 跳到最終值。
- 第二頁：卡片翻面揭曉姓名，揭曉特效依每個人的 `effects` 陣列決定。特效跟著人走，調整順序不會改變。
  - 揭曉前（有任一項就先停 3 秒，期間不能前進）：`聚光燈`、`倒數`（3、2、1）、`鼓聲`（小鼓滾奏，最後一擊落在姓名出現的瞬間）
  - 揭曉時：`鐘聲`、`彩帶`、`鈸聲`、`號角`、`煙火`
  - 沒寫 `effects` 的人預設是 `["鐘聲", "彩帶"]`。名稱打錯時開頁就跳出提示。
  - 預設值：321、瘋狂麥克、強迫症患者加上揭曉前三項；葡萄OvOb 再加 `鈸聲`、`號角`、`煙火`。
- 彩帶量與鐘聲層次隨頒獎順序遞增，越後面越多。
- 彩帶使用 `canvas-confetti` 1.9.3（MIT），從 jsDelivr 下載後存進 `assets/vendor/`，會場沒網路也能播。
- 音效用 Web Audio API 即時合成（翻卡的「咻」聲、揭曉的鐘聲與和弦、鼓聲、鈸聲），不下載音效檔，因此沒有授權問題，也不必帶額外檔案。
  - 取捨：合成的聲音比錄音檔單薄。播起來不滿意的話，可以換成你提供的音效檔，載入方式改成 `<audio>`。
  - 瀏覽器規定要先有使用者操作才能發出聲音。第一次按鍵或點擊就算數，所以封面頁不會有聲音。

## 真實姓名

- 姓名放在 `assets/js/awards-names.local.js`，用暱稱對應姓名：

  ```js
  window.AWARD_NAMES = {
    葡萄OvOb: "王小明",
  };
  ```

- `.gitignore` 加入 `*.local.js`，這個檔案不會進 Git。repo 另外放一份 `assets/js/awards-names.example.js` 當格式範本，內容是假名。
- 檔案不存在或沒有某人的姓名時，第二頁顯示「（尚未設定姓名）」，彩排時一眼就看得出漏填。

## 檔案

- `awards.html`：新頁面，直接雙擊就能用 `file://` 開啟。不用 `fetch`，姓名檔用 `<script>` 載入。
- `assets/css/awards.css`：投影頁專用的樣式，以 16:9 為準，字級放大。配色沿用 `styles.css` 的 `:root` 變數。
- `assets/js/awards.js`：得獎名單、換頁、動畫與音效。
- `assets/vendor/canvas-confetti.min.js`：第三方檔案，不在 `npm run lint` 的檢查範圍內。

## 成果

第一版已完成，等你看過畫面、試過音效後再調整，所以狀態維持「實作中」。

- 與計畫的差異：
  - 卡片的高度改成跟著內容長。原本固定高度，兩個獎項的卡片會超出邊框。
  - 原本的 `.eyebrow` 和 `styles.css` 的同名 class 衝突，改名為 `.awards-eyebrow`。`styles.css` 的全域 `ul` 顏色也在 `.card-awards` 裡覆寫掉。
  - 重新整理後會停在原本那一頁，頁碼記在網址的 `#頁碼`。彩排時可以直接跳到某一頁，例如 `awards.html#18` 是最後一位的第一頁。
- 驗證：
  - `npm run lint` 通過。
  - 在瀏覽器中檢查 1280×720 的封面、說明頁、單獎卡片、雙獎卡片、翻面與彩帶。
  - 最後一位的倒數期間不能前進，按 ← 會中斷倒數。
  - 用 headless Edge 以 `file://` 開啟 1920×1080：有姓名檔時顯示姓名，沒有時顯示「（尚未設定姓名）」，彩帶套件可以從本機載入。
- 已知限制：
  - 音效只確認程式有執行，沒有實際聽過，請你用電腦喇叭試聽。
  - 瀏覽器規定封面頁不會有聲音，第一次按鍵後才會出聲。
  - 沒有在會場的投影機上測過。
- 後續待辦：填入真實姓名，在會場彩排。

## 變更紀錄

- 2026-10-18：揭曉特效從「最後一位固定有倒數」改成每個人用 `effects` 陣列自由組合。原做法的問題是特效綁在順序上，沒辦法指定哪些人要倒數。
- 2026-10-18：試播後發現鼓聲像雜訊。原本只有一連串高頻雜訊，重做成小鼓滾奏：每一擊有鼓皮雜音和鼓身低音，速度由慢漸快、音量漸強。
