# N-Partner Wellness Challenge 2026

Static GitHub Pages site for the N-Partner / HAHAGO wellness challenge.

## Structure

- `index.html` — activity landing page
- `walking.html` — public step-ranking challenge details
- `health.html` — health management challenge details
- `assets/css/styles.css` — shared styles
- `assets/js/app.js` — small progressive-enhancement scripts
- `images/` — image assets, including the temporary SVG brand mark

## Quality checks

```bash
npm run format
npm run lint
```
